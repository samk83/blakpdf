# SPEC: BlakPDF MVP (Bluebeam 유사 PDF 도면 검토 앱)

> 무엇을 만들고, 언제 "다 됐다"고 할지 정하는 문서. 기능 조사 근거: Owner PC의 Bluebeam Revu 21 기능 목록(클린룸 관찰, `docs/PLAN.md` 참고).
> 개발은 이 문서의 **수락기준**이 모두 통과해야 COMPLETED다.
> 마지막 수정: 2026-10-20

## 1. 목표
Windows에서 PDF 도면을 열어 마크업(주석)을 달고, 축척을 맞춰 길이·면적을 재고, 마크업 목록을 표로 보고 CSV로 내보내는 데스크톱 앱. Bluebeam의 코드·아이콘·에셋은 쓰지 않고 오픈소스로 새로 만든다.

## 2. 범위
| 만들 것 | 안 만들 것 (이번 범위 밖) |
|---|---|
| PDF 열기/저장/다른 이름 저장, 확대·축소·맞춤, 화면 이동, 페이지 이동, 썸네일 | 분할 화면, 책갈피, 텍스트 검색 |
| 마크업: 선·화살표·사각형·타원·다각형·구름·텍스트·콜아웃·메모·펜·형광펜 | 스탬프, 하이퍼링크, 3D, 첨부 |
| 선택·이동·삭제, 실행 취소/다시 실행, 속성(색·두께·투명도·내용) | 정렬·그룹, 도구 세트·프로필 |
| 측정: 축척 보정, 길이, 면적, 둘레, 개수 | 각도, 부피, 비용 수식 |
| 마크업 목록: 표, 정렬·필터, 클릭 시 위치로 이동, CSV 내보내기 | 답글·상태, PDF 보고서 |
| 표준 PDF 주석으로 저장 (다른 PDF 앱에서도 보임) + 다시 열면 편집 가능 | 비교·겹쳐보기, OCR, 일괄 처리, Studio 협업, 디지털 서명 |
| 라이트/다크 테마 | 설치 프로그램(인스톨러) 배포 |

## 3. 수락기준
| # | 수락기준 | 확인 방법 | 상태 |
|---|---|---|---|
| 1 | PDF 파일을 열면 첫 페이지가 화면에 그려지고 왼쪽에 모든 페이지 썸네일이 보인다 | E2E 테스트 | ☐ |
| 2 | 확대/축소(버튼, Ctrl+휠), 폭 맞춤, 페이지 이동(썸네일 클릭, 이전/다음)이 동작하고 상태 표시줄에 배율·페이지가 보인다 | E2E 테스트 | ☐ |
| 3 | 11가지 마크업 도구(선·화살표·사각형·타원·다각형·구름·텍스트·콜아웃·메모·펜·형광펜)로 그리면 화면에 남고 목록에 1행씩 추가된다 | E2E + 단위 테스트 | ☐ |
| 4 | 마크업을 선택해 이동·삭제할 수 있고, 속성 패널에서 색·두께·투명도·내용을 바꾸면 즉시 반영된다 | E2E 테스트 | ☐ |
| 5 | Ctrl+Z / Ctrl+Y로 추가·이동·삭제·속성 변경을 되돌리고 다시 할 수 있다 | 단위 테스트 | ☐ |
| 6 | 두 점과 실제 거리를 입력해 축척을 보정하면 그 페이지의 길이·둘레·면적 값이 그 단위로 계산된다 (예: 100pt=1m 보정 시 200pt 선은 2.00 m) | 단위 + E2E 테스트 | ☐ |
| 7 | 길이·면적·둘레·개수 측정 도구가 도면 위에 값 라벨을 표시하고 목록에 측정값 열로 나온다 | E2E 테스트 | ☐ |
| 8 | 마크업 목록을 열 기준으로 정렬·텍스트 필터할 수 있고, 행을 클릭하면 그 페이지로 이동해 해당 마크업이 선택된다 | E2E 테스트 | ☐ |
| 9 | CSV 내보내기 파일에 페이지·종류·내용·색·측정값·단위·작성자·날짜 열이 있고 엑셀에서 한글이 깨지지 않는다(UTF-8 BOM) | 단위 테스트 | ☐ |
| 10 | 저장한 PDF는 마크업이 표준 PDF 주석(/Annot)으로 들어가 다른 뷰어(pdf.js)에서도 보이고, BlakPDF로 다시 열면 마크업이 편집 가능한 상태로 복원된다 | 단위 테스트(왕복) | ☐ |
| 11 | 저장하지 않은 변경이 있으면 제목에 표시되고, 창을 닫을 때 확인을 묻는다 | 코드 확인 + Owner 실행 | ☐ |
| 12 | Windows에서 `npm install` → `npm start`로 앱이 실행된다 | Owner PC 실행 | ☐ |
| 13 | 라이트/다크 테마 전환이 되고 주요 글자 명도 대비가 4.5:1 이상이다 | contrast.py | ☐ |

상태: ☐ 미완 · ✅ 통과(리뷰어 확인) · ❓ 미확인(이유를 적음)

## 4. 리스크
| 리스크 | 대응 |
|---|---|
| 큰 도면 PDF 렌더링이 느림 | 보이는 페이지만 렌더, 썸네일은 저해상도 지연 렌더 |
| 저장 시 원본 손상 | 원본 덮어쓰기 전 메모리에서 새 PDF를 만든 뒤 한 번에 씀, "다른 이름 저장" 제공 |
| Bluebeam 지식재산 | 기능 관찰만, 코드·아이콘·에셋 복사 금지. 아이콘은 Lucide |
