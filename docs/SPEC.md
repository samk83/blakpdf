# SPEC: blakpdf — Bluebeam 비슷한 PDF 마크업 데스크톱 앱 (v0.1)

> 무엇을 만들고, 언제 "다 됐다"고 할지 정하는 문서. 기획 배경은 `docs/PLAN.md`.
> 개발은 이 문서의 **수락기준**이 모두 통과해야 COMPLETED다.
> 마지막 수정: 2026-10-20

## 1. 목표
Windows PC에서 도면·문서 PDF를 열어 Bluebeam Revu처럼 마크업(표시)하고, 거리를 재고, 마크업이 들어간 PDF로 저장하는 프로그램을 React + Electron으로 만든다.

## 2. 범위
| 만들 것 | 안 만들 것 (이번 범위 밖) |
|---|---|
| PDF 열기 (메뉴·단축키·끌어다 놓기) | 클라우드 협업 (Bluebeam Studio 같은 것) |
| 확대/축소, 화면 맞춤, 페이지 이동, 썸네일 | OCR (그림 속 글자 인식) |
| 마크업 도구: 선택, 펜, 형광펜, 선, 화살표, 사각형, 원, 구름(리비전 클라우드), 텍스트 | 도면 비교 (Overlay/Compare) |
| 색·선 굵기·투명도 설정 | 로그인·결제·서버 |
| 측정: 축척(Calibrate) 설정, 길이 측정 | 면적·부피 측정, 개수 세기 |
| 마크업 목록 (종류·페이지·내용, 클릭하면 이동, 삭제) | 기존 PDF 주석(annotation) 읽어 와서 편집 |
| 실행 취소/다시 실행 | 코드 서명, 자동 업데이트, 설치 파일 배포(L3) |
| 마크업을 PDF 페이지에 그려 넣어 저장 (다른 이름으로 저장) | |

## 3. 수락기준
| # | 수락기준 | 확인 방법 | 상태 |
|---|---|---|---|
| 1 | PDF를 열면 첫 페이지가 화면에 보이고, 페이지 수와 썸네일 목록이 보인다 | 자동 테스트 (Playwright 브라우저) | ✅ |
| 2 | 확대/축소 버튼·Ctrl+휠·화면 맞춤이 동작하고 배율(%)이 표시된다. 다음/이전 페이지·페이지 번호 입력으로 이동한다 | 자동 테스트 | ✅ |
| 3 | 펜·형광펜·선·화살표·사각형·원·구름·텍스트 도구로 페이지 위에 마크업을 그릴 수 있고, 선택 도구로 골라 이동·삭제(Delete 키)할 수 있다 | 자동 테스트 + 단위 테스트 | ✅ |
| 4 | 색·선 굵기·투명도를 바꾸면 새로 그리는 마크업과 선택한 마크업에 적용된다 | 자동 테스트 | ✅ |
| 5 | 축척 설정에서 알고 있는 길이의 두 점을 찍고 실제 길이(예: 5 m)를 입력하면, 길이 측정 도구가 그 축척으로 값을 표시한다 | 단위 테스트 + 자동 테스트 | ✅ |
| 6 | 마크업 목록에 모든 마크업(종류·페이지·내용/측정값)이 나오고, 항목 클릭 시 그 페이지로 이동·선택되며, 목록에서 삭제할 수 있다 | 자동 테스트 | ✅ |
| 7 | Ctrl+Z / Ctrl+Y로 마크업 추가·이동·삭제·속성 변경을 되돌리고 다시 할 수 있다 | 단위 테스트 | ✅ |
| 8 | 저장하면 마크업이 그려진 새 PDF가 만들어지고, 그 PDF를 다시 열면 같은 위치에 마크업이 보인다 (페이지 수 유지) | 단위 테스트 (pdf-lib 결과 검사) + 자동 테스트 | ✅ |
| 9 | Electron 데스크톱 앱으로 실행되고, 파일 메뉴(열기 Ctrl+O / 저장 Ctrl+S / 다른 이름으로 저장)가 동작한다. Windows용 실행 파일 빌드 명령이 있다 | Linux에서 Electron 실행 확인, Windows 실기는 Owner 확인 | ❓ Linux Electron ✅, Windows 실기 미확인 |

상태: ☐ 미완 · ✅ 통과(리뷰어 확인) · ❓ 미확인(이유를 적음)

## 4. 리스크
| 리스크 | 대응 |
|---|---|
| 클라우드(Linux)에서 Windows 실행 직접 확인 불가 | 같은 코드를 브라우저·Linux Electron으로 자동 테스트, Windows 실행은 Owner 확인 항목으로 남김 |
| 아주 큰 도면 PDF는 느릴 수 있음 | 보이는 페이지만 그리기(필요할 때 렌더링) |
| 저장 시 마크업이 "그림으로 박혀" 나중에 다른 프로그램에서 편집 불가 | v0.1 범위로 명시. 편집 가능한 PDF 주석 저장은 추가 개선 추천 |
