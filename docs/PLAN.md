# 기획: blakpdf

## Owner 요청 (2026-10-20)
> React를 이용해서 나한테 설치된 Bluebeam이랑 비슷한 프로그램 만들어줘. (형태: Windows 데스크톱 앱)

## 정리
- 목적: 건설·설계 도면 PDF를 검토하며 표시(마크업)하고 치수를 재는 PC 프로그램. Bluebeam Revu의 핵심 작업 흐름을 무료로.
- 사용자: Owner 본인 (도면 검토자)
- 사용 환경: Windows PC, 마우스·키보드
- 화면: ① 시작 화면(열기) ② 작업 화면 = 위 도구 막대 / 왼쪽 썸네일 / 가운데 도면 / 오른쪽 속성·마크업 목록 / 아래 상태 표시줄 ③ 텍스트 입력·축척 설정 창

## 꼭 필요 (v0.1 → `docs/SPEC.md` 수락기준)
열기, 확대/축소·페이지 이동, 마크업 9종, 색·굵기·투명도, 축척 설정·길이 측정, 마크업 목록, 실행 취소, 마크업 넣은 PDF 저장, PC 프로그램 메뉴

## 나중에 (범위 밖)
면적·개수 측정, 편집 가능한 PDF 주석으로 저장, 마크업 작업 파일 저장/불러오기, 여러 쪽 연속 스크롤, 도면 비교, OCR, 클라우드 협업

## 검토 메모
- 저장 방식: v0.1은 마크업을 페이지에 "그려 넣는" 방식(평탄화). 다른 PDF 프로그램에서 마크업을 다시 편집할 수 없다 → 원본을 덮어쓰지 않고 `원본_markup.pdf`로 따로 저장하게 함.
- 회전된 페이지(/Rotate)가 있는 PDF는 저장 위치가 어긋날 수 있다 → 남은 문제로 기록.
