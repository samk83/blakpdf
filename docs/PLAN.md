# PLAN: BlakPDF

## 배경
Owner가 PC에 설치된 Bluebeam Revu 21과 비슷한 PDF 도면 검토 프로그램을 개인 실험으로 만들고 싶어 함 (2026-10-20). 처음부터 끝까지 Claude가 자율 진행, 디자인 결정도 위임.

## 조사 방법 (클린룸)
Owner PC에서 원격 세션으로 **읽기만** 했다. 설치 폴더의 파일 이름·버전 정보, .NET/네이티브 구분(메타데이터), 파일 연결, 기본 도구 세트·프로필·스탬프 파일 이름, 단축키 명령 이름, 기능 플래그 이름. 디컴파일은 하지 않았고 코드·아이콘·에셋은 복사하지 않았다. 원본 조사 결과는 Owner PC의 `C:\Dev\bluebeam-analysis\FEATURES.md`.

## 조사 결과 요약 (우선순위)
| 영역 | MVP (이번에 만듦) | 나중에 | 안 함 |
|---|---|---|---|
| 열기·보기·탐색 | 열기/저장, 확대·축소, 화면 이동, 페이지 이동, 썸네일 | 분할 화면, 책갈피, 검색 | 시각 검색 |
| 마크업 | 선·화살표·사각형·타원·다각형·구름·텍스트·콜아웃·메모·펜·형광펜, 선택·이동·편집, 실행 취소, 속성 | 스탬프, 하이퍼링크, 정렬·그룹, 선 스타일 | 3D, 첨부 |
| 도구 상자·프로필 | (도구별 기본값 기억) | 도구 세트, 프로필 | – |
| 마크업 목록 | 표, 정렬·필터, 클릭 이동, CSV | 답글·상태, PDF 보고서 | Excel 링크 |
| 측정 | 축척 보정, 길이, 면적, 둘레, 개수 | 각도, 부피, 비용 수식 | 동적 채우기 |
| 페이지 편집 | – | 삽입·삭제·회전, 평면화 | 압축, 보안 |
| 비교·세트·레이어 | – | 비교, 겹쳐보기, 세트, 레이어 | 파일 관리자 |
| 일괄·OCR·양식·서명 | – | 일괄 링크, OCR, 양식 채우기 | XFA, JS, 디지털 서명 |
| 협업·변환·AI | – | 자체 MCP 서버 | Studio, CAD·Office 플러그인 |

## 기술 관찰 (참고)
원본은 .NET Framework 4.8 + WPF, 자체 PDF 엔진. 우리는 오픈소스(pdf.js + pdf-lib)로 같은 역할을 새로 구현한다.
